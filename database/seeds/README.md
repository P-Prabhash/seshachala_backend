# Database Seeds

This directory contains database seeding scripts and instructions.

## Default Seed Accounts
- Administrator: `admin` / `admin123` (Role: Admin)
- Staff: `staff` / `staff123` (Role: Staff)

## Default Settings & Reference Data
- Academic Year: `2026–27` (Active)
- Course: `B.Pharm` (4 Years, Active)
- College Name: `Seshachala` / `College of Pharmacy`
- App Settings: Fee types, receipt prefix (`SCP`), payment modes (`Cash,UPI,Card,Check`).

## How to seed
Run via npm script:
```powershell
npm run seed
```
